# NextMind-AI website

First usable public website for NextMind-AI, an early-stage IT services company focused on websites and software for businesses, including the real-estate industry.

## Run locally

Serve the repository directory with any static server, for example:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.
